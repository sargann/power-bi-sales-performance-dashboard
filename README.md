# Sales Performance Dashboard

## Project Overview

This project is an interactive Power BI dashboard created to analyze sales performance, profitability, orders, and business trends using the Sample Superstore dataset.

The dashboard is designed to help users quickly identify sales trends, compare performance across regions and categories, and evaluate profitability.

## Key Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Sales trend over time
- Sales by category
- Sales by region
- Profit by sub-category
- Top 10 products by sales
- Interactive slicers for Region, Category, and Segment
- Conditional formatting for profitability analysis

## Tools & Technologies

- Power BI Desktop
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Key Insights

The dashboard allows users to:

- Compare sales performance across regions
- Identify the strongest and weakest product categories
- Analyze profitability by sub-category
- Identify top-performing products
- Explore sales trends over time
- Filter the analysis by region, category, and customer segment

## Dataset

The project uses the Sample Superstore dataset for demonstration and portfolio purposes.

## Project Goal

The goal of this project was to create a clear, interactive, and business-focused dashboard that transforms raw sales data into actionable insights.
